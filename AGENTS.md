# Capmit

- Product: Capmit, for university students.
- Stack: Next.js App Router + TypeScript + Tailwind.
- Prototype only; use local state and mock data.
- Do not change the locked Aina demo values.
- Do not invent features beyond the requested screen.
- UI work must invoke $capmit-frontend.
- Implement and verify one screen at a time.
- No backend, API, database, or auth unless explicitly requested.
